# posit-python

reference-grade pure-python implementation of the latest [posit standard](https://posithub.org/docs/posit_standard-2.pdf)

# install

```sh
pip install posit_python
```

# example

```python
from posit_python import posit

posit8 = posit(8)

posit8(hoge)
# fuwa
```

# features

* 🚧 posit format
* 🚧 quire format
